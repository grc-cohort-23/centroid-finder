# Project Goals

## Theme: Basketball Tracker

Our goal is to extend the existing Centroid Finder application to track a basketball's movement in a video using color and centroid detection.

## Easy

- Add backend functionality to calculate the distance the basketball moves between consecutive video frames using existing centroid coordinates.

## Goal

- Calculate the total distance traveled by the basketball in pixels.
- Display the basketball's movement information on the frontend.

## Stretch

- Display a visual path showing the basketball's movement throughout the video.

## Impossible

- Build a real-time basketball tracking system that automatically detects players, basketballs, and successful shots during live games.
